# 标注与统计规则

本库的单位是**研究文章 × 已确认的方法概念**。它是支持ACM整合综述的定向方法目录，v0.1不是完整系统综述。

## 三种统计队列

| 队列 | 定义 | 当前分母 |
|---|---|---:|
| `manuscript` | 被综述实际引用的正式原始研究，含病例系列 | 23篇 |
| `peer_reviewed` | 目录内全部正式原始研究 | 24篇 |
| `all` | 全部原始研究记录，另含明确标识的预印本 | 25篇 |

14项指南、共识、已有综述、试验注册和会议资料放在 `context_sources.json`，不进入上述分母。并行发表和预印本/正式版不作为两篇独立研究计数；保留的DSP分期预印本没有在本轮核实到正式版。

## 阳性标注与缺失

- 有明确原文或既有审读依据，才能标为使用了某方法。
- `verified_local_text`：核对了相关原文、方法或图注。
- `verified_existing_audit`：依据此前保留的原文阅读/数据核验记录，本轮没有重新逐图通读。
- `abstract_only`：只采用摘要能明确支持的方法，不推测软件、平台或实现。
- **没有记录是未确认，不是确认没有使用。** 不输出“未使用某方法”的0/1矩阵，也不把标注数当作方法丰富度或研究质量。
- 所有标注由AI辅助整理并经过针对性独立AI核查；尚未经过两名人类研究者独立全文编码，不报告虚构一致性系数。

v0.1各文献的核对深度不同。特别是有较完整可读方法的研究会有更多细项；统计只描述**当前库中已确认方法的标注频次**，不能解释为整个ACM领域的使用率或发展趋势。

## 四个方法维度

| family | 含义 |
|---|---|
| `design` | 临床/取材/时间设计、模型系统和观察性治疗比较 |
| `measurement` | 组学、影像、电生理及细胞/分子测量，含明确复用的数据类型 |
| `computational` | 表达、通路、网络、配准和临床统计等计算分析 |
| `intervention` | 受控的临床前遗传、药理或刺激扰动；不是患者疗效验证的同义词 |

方法概念与具体软件分开。Seurat、CellChat、Tangram等工具在逐篇证据说明中记录；同类算法不会因多个软件名重复变成多篇研究。上下位概念可以同时存在，**不得把子类频数直接相加**。`group_id`与family的汇总都按研究去重。

## 特别保留的区别

1. 受控分批时间序列、同人随访、重复影像、横断面分期和计算拟时序各有标签。
2. 微阵列与RNA-seq分开；CITE-seq、单细胞与单核分别标记。
3. TomoSeq切片表达模式与细胞生态位共定位分开。空间排列不提供疾病传播方向。
4. 模型创建、功能缺失、下游机制救援和AAV病因补充分开。基因救援不自动代表临床治疗。
5. 观察性用药、病例治疗和受控干预分开；无对照病例不能标为RCT。
6. `data_origin`只在已核实处填`generated`或`reused`，其余为`not_classified`。RNA数据“使用”不等于本研究重新测序。
7. 临床问题映射是综述组织框架，不是经过验证的诊断分期、风险评分或处方规则。

## 计算公式与可复现性

方法出现比例 = 当前队列中有该阳性标注的**不同文章数** ÷ 当前队列文章数 × 100%。同篇多标签，因此百分比之和可以超过100%。

共现数 = 同时标注两种方法的文章数。共现不证明方法因果联系、优劣或临床效用。方法组合、样本量和临床结局不能由这种计数代替。

研究年份描述的是本定向样本的构成，不估计年度领域产出。论文之间可能复用患者或公共数据，文章数不等于独立队列数。相关说明逐篇保留。

运行 `python3 scripts/build_atlas.py` 可从公开JSON重建统计、CSV和静态页面。该命令复现的是标注库的汇总；原文章节的语义判断需要阅读原始来源。部分定位指既有审读字段，已经按标注层级区分。
