# 与既有综述的关系

本页为定向比较及项目定位，不是穷尽性创新查新。GitHub开放本身不等同新的生物机制、临床有效性或完整范围综述。

| 相近综述 | 已有贡献与重叠 | 本项目拟增加的可检验内容 |
|---|---|---|
| [Bassetto等，Current Cardiology Reports，2025](https://link.springer.com/article/10.1007/s11886-024-02168-6) | 连接热相的机制、多模态诊断及潜在治疗。 | 将每个研究内关系的时间、空间、扰动和结局依据结构化，使跨研究连接可复核。 |
| [Zarghami等，JACC Advances，2026](https://www.jacc.org/doi/abs/10.1016/j.jacadv.2026.103154) | 整合机制、影像、遗传和电生理，将热相视作慢性基质上的动态电不稳定状态。 | 对同人、同区、真实时间或人体比较干预的要求逐问题列明，区分已有片段与目标临床主张。 |

当前已实现三条路径、29条选定关系、六个桥接问题及可重建输出。作为论文的主要贡献，应在完整检索与人类复核后进一步判断哪些连接得到哪些直接支持；不能将先导库中的未检出当领域不存在。

后续可验证的增量包括：独立编码者能否依据原文重复得到这些标签；来源扩展、仅人体、仅真实时间或排除病例/摘要级研究后，桥接判断是否变化；条件表能否导出比笼统“需要更多研究”更明确的研究对象、测量、对照和结局。当前均未声称已完成这些验证。
